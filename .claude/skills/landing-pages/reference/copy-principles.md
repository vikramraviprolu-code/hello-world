# Copy principles — write it so it converts

Distilled from widely-known copywriting/writing-well principles (associated
with Julian Shapiro's handbooks), in our own words. The human-conversion
mirror of geo's anti-slop pass — run both together on any product copy.

## 1. Clarity first, always

A confused reader bounces; they don't puzzle it out. Before you make a line
persuasive, make it unambiguous. If a sentence needs re-reading to parse,
it has already lost. Prefer plain words over jargon, concrete over abstract.

## 2. Lead with the benefit, not the feature

Readers care about the outcome for *them*, not your mechanism. State the end
result, then (if useful) how you deliver it.

- Feature: "Local flag evaluation with edge caching."
- Benefit-led: "Flags resolve in under 1 ms, so your app never waits on us —
  powered by local evaluation."

The mechanism earns trust *after* the benefit earns attention.

## 3. Specificity is persuasion

Vague claims read as marketing noise and get mentally discounded. Concrete,
specific, ideally numeric claims read as true.

- Weak: "blazing fast and loved by developers."
- Strong: "0.8 ms p99 evaluation; 4.9/5 across 1,200 reviews."

Specificity also happens to be what AI engines cite (see geo) — the same
edit serves both audiences.

## 4. The delete test

Read each sentence and ask: *would the reader lose anything if this were
gone?* If not, cut it. Filler dilutes the sentences that matter. Ruthless
subtraction is the highest-leverage edit. A shorter page that says one thing
clearly beats a long one that hedges.

## 5. The hook chain

The job of the headline is to make them read the subhead. The job of the
first sentence is to make them read the second. Copy is a chain — each link
earns the next. Open sections with the most interesting or valuable thing,
not a warm-up. Never bury the point beneath throat-clearing.

## 6. Write to one person

Address a single reader ("you"), not "users" or "businesses". Pick the one
primary audience and write as if to them alone; trying to speak to everyone
speaks compellingly to no one.

## 7. Strip the slop (shared with geo)

Cut on sight: "in today's fast-paced world", "unlock/empower/supercharge/
elevate", "seamless", "cutting-edge", "game-changer", "robust" (unless
quantified), and rule-of-three padding. Every sentence must carry a fact or
a genuine benefit, or it goes. Cited text is quoted text; converting text is
trusted text — both require the same discipline.

## 8. Honesty converts and protects

Don't fabricate testimonials, user counts, or metrics to sound impressive.
Beyond the trust cost when a claim rings false, for a real product invented
proof is a legal exposure. If proof is missing, tell the user to get it —
never invent it.

## Editing pass (run in order)

1. Does the hero pass the 5-second test? (what / who / next action)
2. Is every headline benefit-led and specific?
3. Delete-test every sentence.
4. Strip slop phrases.
5. One CTA goal, one audience, front-loaded points.
6. Every proof claim real and, ideally, specific.
